# WebEduca

## Descrição

O WebEduca é um portal educacional desenvolvido como atividade prática da disciplina de Programação Web I, do curso de Engenharia de Software da UEPA.

O projeto utiliza HTML, CSS e JavaScript para apresentar cursos de tecnologia e permitir pesquisas por nome e categoria.

## Tecnologias utilizadasa

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Exibição de cursos de tecnologia.
- Organização dos cursos por categorias.
- Pesquisa de cursos pelo nome.
- Filtro por categoria.
- Mensagens informando a quantidade de cursos encontrados.
- Layout adaptado para telas pequenas.

## Melhorias implementadas

Na atividade do Capítulo 7, foram adicionadas categorias aos cursos, um filtro por categoria e uma seção de apresentação do projeto.

Também foram melhoradas as mensagens de retorno da pesquisa, permitindo informar quando nenhum curso é encontrado.

## Como executar

1. Abra a pasta do projeto.
2. Localize o arquivo `index.html`.
3. Abra o arquivo em um navegador.
4. Utilize o formulário para pesquisar e filtrar os cursos.

## Estrutura do projeto

- `index.html`: estrutura da página.
- `style.css`: estilos e responsividade.
- `script.js`: catálogo e filtros dos cursos.
- `README.md`: documentação do projeto.
